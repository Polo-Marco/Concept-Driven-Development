Review v8.0 against the loop-engineering literature (uploaded IEEE

## Changes (v8.1)

Installed the v8.0 machinery (`cp -r v8.0-draft/_claude/. .claude/`,
which satisfies PATCHES §1–3 since the staged rules were pre-patched),
then applied:

**`.claude/driver/loop.py`** — four deterministic gates, run cheapest
first before anything is spent: `machinery()` (parts installed + hook
wired, else abort rather than degrade), `validate_goal()` (contract
well-formed, ≥1 machine-checkable criterion, budgets present),
`require_isolation()` (refuse the primary working tree), `preflight()`
(per-goal environment checks, exit-code gated, output discarded so a
bad check cannot leak a key). Plus `check_criteria()` — reads every
criterion off disk, fail-closed — wired in three places: per-ticket
telemetry into the ledger, a regression guard that forces RETRY when a
green criterion goes red, and the final hard gate ahead of the
Evaluator. Fixed: `max_usd` enforced; GPU-hours billed from trial start
and charged incrementally so a cap can trip mid-trial; a killed
crash-class trial returns False instead of being evaluated; contract
review fails closed on a missing/corrupt verdict; stale verdicts
unlinked before each Evaluator call.

**`.claude/agents/cdd-evaluator.md`** — assume-broken default; Mode 2
must execute and paste real output (evidence is observation, not
description); new provenance audit; Mode 1 gains **Sourced?** (does a
ticket actually produce each criterion's source file) and **Faithful?**
(does `goal.json` preserve `Goal.md`'s meaning — maker–checker on the
translation step).

**`skills/mode-loop/SKILL.md`** (v8.1) — step 0 machinery self-check
that refuses rather than degrades; criteria interrogation now demands
"who writes that file"; a Preflight section; `Goal.md` given a
predictable shape so translation is mechanical; read-back by the JSON's
semantics closing with "nothing else is checked"; worktree required;
all `[Halt here]` instructions removed.

**Rules/docs** — `loop-protocol.md` principles 6–7 (rule-bound work is
decided by code; deterministic is necessary but not sufficient), three
gates stated explicitly, halt removal and its rationale;
`task-ticket-format.md` and README mark `[Halt here]` manual-mode-only;
design doc §5 gains the criteria shape, the Preflight section, and a
derivation-drift analysis with its two controls; hook protects
`events.jsonl`; version bumps in `CLAUDE.md`, README (+ history row),
`mode-loop`, hook, driver.

**`.claude/driver/test_loop.py`** — new. 48 offline tests, no API key
and no `claude` login: every v8.0 defect above has a test that pins it,
plus a stubbed-Claude run of the whole state machine and a 9-case
deny/allow matrix driving the real PreToolUse hook with crafted JSON.
This is the offline half of INSTALL.md's M1/M2.

## Deliberately not adopted

Discovery and scheduling (goal loop ≠ maintenance loop — see
`docs/inbox.md` 2026-07-30), connectors, parallelism expansion, the
six-level permission ladder. Worktree creation *detects and refuses*
rather than creating-and-re-execing: an untested re-exec inside the
process that owns every commit is the wrong place to be clever, and
this session could not test it.

## Consequence the user should hold

Removing the only mid-loop human checkpoint moves all human judgment to
the Ask phase and the plan gate. Nothing catches a bad goal mid-flight
any more. That promotes three things from "should fix" to load-bearing:
the budget caps, the **Faithful?** translation audit, and tighter
`max_iterations` defaults for a first unattended run. The sampling
habit at loop end is now the only guard against comprehension rot.
